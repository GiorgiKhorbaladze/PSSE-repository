# სსე PSS/E Dynamic Simulation Report Dashboard

ბრაუზერზე დაფუძნებული (static) პროფესიონალური დაფა PSS/E დინამიკური სიმულაციის შედეგებისთვის.
ინტერფეისი აგებულია Georgian State Electrosystem (სსე) სტილში: თეთრი/ღია-ნაცრისფერი ფონით,
წითელი აქცენტით, sticky ნავიგაციით, KPI ბარათებით და ავტომატური ანგარიშგებით.

## როგორ გავუშვა ლოკალურად

1. რეპოზიტორიის ჩამოტვირთვის შემდეგ გახსენით `index.html` პირდაპირ ბრაუზერში.
2. ალტერნატივად შეგიძლიათ გაუშვათ უბრალო static server:
   - `python3 -m http.server 8080`
   - შემდეგ გახსენით `http://localhost:8080`

> დაფა იმუშავებს დაუყოვნებლივ დემო მონაცემებით, ატვირთვის გარეშე.

## ავტომატური ანალიტიკა

თითოეული სცენარისთვის ითვლება:
- მინიმალური სიხშირე
- მაქსიმალური სიხშირის გადახრა
- მინიმალური ძაბვა
- მაქსიმალური აქტიური სიმძლავრის გადახრა
- მაქსიმალური რეაქტიული სიმძლავრის გადახრა
- ყველაზე მძიმე არხი
- ყველაზე მძიმე მოვლენის დრო
- დამშვიდების დროის შეფასება
- სტაბილურობის სტატუსი: Stable / Warning / Critical

## ზღვრები (Thresholds)

### სიხშირე
- Normal: `>= 49.8 Hz`
- Warning: `49.5 – 49.8 Hz`
- Critical: `< 49.5 Hz`

### ძაბვა
- Normal: `>= 0.90 p.u.`
- Warning: `0.85 – 0.90 p.u.`
- Critical: `< 0.85 p.u.`

ეს ზღვრები ნაჩვენებია გრაფიკებზე threshold ხაზებით.

```js
    speed: {},

  }
}
```

  დანარჩენი UI/ანგარიშგების ფენა უცვლელად იმუშავებს.
